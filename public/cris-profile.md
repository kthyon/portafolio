## Nexo — creator and instructor
Nexo brings the learning journey, interactive examples, reference concepts and Python/Colab exercises into one teaching interface. It also supports individual progress, notes and a connected teacher view. The visual tools support the explanation; notebooks provide the environment for full model training and inference.
Architecture: HTML, CSS and JavaScript modules. Interactive calculations, accessible controls and Three.js scenes with a 2D fallback. Static learning content and notebooks, versioned with Git and delivered through GitHub Pages. Same-origin JavaScript API on Sites. Server-side identity and role checks separate each student’s records from teacher administration. Cloudflare D1 / SQLite: students, courses, topics, enrollments, progress and notes. Record ownership uses authenticated identity. Python notebooks in Google Colab. Students work on personal copies; model execution is separate from the visual interface. Browser progress and pending changes remain local when synchronization is unavailable. Personal export/import supports continuity.
Pending browser changes are retained for retry. Related record writes are batched, and saves are queued within each browser. The current API saves snapshots; simultaneous edits from multiple devices can overwrite each other, so this design does not provide automatic conflict merging.
The public case contains demonstration screenshots without real student records. Guided demonstrations are available by contact.
Case study: https://kthyon.github.io/portafolio/work/nexo/
